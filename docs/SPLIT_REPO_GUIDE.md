# 前后端分仓 · 双仓接入说明

适用：`meta.repo_layout = split`。

## 原则

| 项                    | 建议                                                         |
| --------------------- | ------------------------------------------------------------ |
| `ai-kit`              | **每个仓各放一份**（或 Submodule 到相同 `ai-kit` 版本）      |
| `PROJECT_BRIEF.md`    | 以 **E10 契约主仓** 为准；主仓写完整简报，另一仓可写缩短版并指向主仓路径 |
| `.cursor/rules/*.mdc` | **每个仓项目根各一份**（`alwaysApply: true`）                |
| OpenAPI / 契约文件    | 只在**主仓**维护路径（`brief_source_of_truth`）              |

## 推荐步骤

1. 在**契约主仓**（通常后端）先跑 `START_HERE.md` 访谈 → 生成全套文档。  
2. 在**另一仓**再跑访谈：A2 标明角色；E6 指回主仓契约路径；可「跳过可选」缩短 P2。  
3. 改接口时：先改契约主仓的 OpenAPI/Controller，再改另一仓客户端/调用方。  

## 勿做

- 不要假设 AI 能同时写入两个不打开的 workspace 路径。  
- 不要在两仓 `PROJECT_BRIEF` 里写不同版本的 API 基址而不注明主仓。
